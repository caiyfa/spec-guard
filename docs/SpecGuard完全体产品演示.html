Capabilities · Now

今天就能用的十项能力

测试人员不写代码，只写 YAML；doc 层即测试文档，执行层即测试脚本。

01

API 级 E2E 场景

HTTP 调用 + JSON 路径断言 + 状态码校验 + DB 校对 + 权限预言，一条链路全覆盖。

→ 不写代码，只写 YAML
02

双层 YAML 用例

doc 层 given/when/then + FR 编号给人看，flow/verify 层给机器跑，评审零翻译成本。

→ 用例即文档
03

依赖 DAG 调度

depends_on 声明上下游，自动拓扑排序、跨模块引用；上游失败下游自动 BLOCKED。

→ 准备用例自动前置
04

写型场景状态管理

shared 只读复用 / exclusive 独占实例双模式，teardown LIFO 清理，写流程不污染环境。

→ 写测试也敢放心跑
05

DB 校对断言器

快照冻结比对、时点过滤、DHR 降级、三维权限过滤等 8+ 预置 oracle。

→ 接口与库一致性自动核对
06

权限预言

实时抓取权限中台数据，ALL / PART / 无权限 fail-secure 全链路自动验证。

→ 告别手工构造账号矩阵
07

断点分段执行

按断点切批次，批间暂停展示上下文，人工确认后再继续。

→ 长链路可中途介入
08

计划驱动执行

测试计划由迭代 delta 导入生成，报告按 plan_id 归档，历史完整可追溯。

→ 回归与需求一一对应
09

诚实的结果语义

数据缺失 → SKIP，上游失败 → BLOCKED，绝不把环境问题报成 FAIL。

→ FAIL 即可疑缺陷
10

发布门禁

契约指纹变更未 bump 版本即拦截，环检测、teardown 缺失告警自动守门。

→ 用例库质量自动保障

Honest Boundaries

我们不做什么 —— 边界清晰才值得信任

七条长期边界写进设计，防止能力误用，也让每一分投入都花在刀刃上。

✕

不做前端 UI 测试

纯后端 API + DB 视角，UI 链路交给专门工具。

✕

不做性能压测

引擎按依赖串行调度，压测走 JMeter 等专用平台。

✕

不替代探索性测试

易用性与业务直觉判断永远属于人。

✕

不写生产数据库

SELECT-only 硬守卫，写操作只走 API 且必须配 teardown。

✕

不造假数据凑通过

SKIP 语义是底线：环境缺失绝不粉饰成 PASS。

✕

Agent 产物不直接执行

人工评审 → 格式校验 → 发布门禁，三道闸缺一不可。

✕

不替代缺陷定性

Agent 只给归因建议，定性与定级永远由测试人员拍板。
