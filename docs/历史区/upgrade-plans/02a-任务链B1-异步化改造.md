# 任务链 B-1：异步化改造

> 优先级：**P1**
> 并行性：⚠️ **高风险独立项**，需在任务链 A 完成后启动，充分回归
> 预计工期：1 周
> 文档依赖：[总览](./00-总览与任务链编排.md)、[任务链 A](./01-任务链A-P0紧急修复.md)（需 A-2 的 compaction 修复先行）
> 后继依赖：B-2（工具并行）、B-3（流式）、C（Provider 分支）都依赖本链的异步基座
> 修正说明：**B-1 是修正版从 B 拆出的独立高风险项**。初版把异步化、工具并行、流式混在一起，回归测试范围过大。修正后 B-1 只做异步化，充分回归后再做 B-2/B-3。

---

## 一、目标

偿还 SpecGuard 智能层的核心技术债：`runtime.py` 与 `llm_client.py` 异步化，消除 `asyncio.run` 每工具一次的事件循环创建/销毁开销。

**本链只做异步化，不做工具并行（B-2）和流式输出（B-3）**——那两项在 B-1 稳定后分别进行。

---

## 二、现状分析（改造前必读）

### 当前调用链（同步）

```
前端 WS → agent.py:333 asyncio.to_thread(runtime.run, ...)
         ↓ （丢进线程池）
         runtime.run() 同步循环
           ↓ for turn:
             llm.chat() 同步 httpx.post（阻塞）
             ↓ for tc: asyncio.run(mod.handle(name, args))  ← 每工具一次新事件循环
           ↓
         事件经 loop.call_soon_threadsafe 推回 async 队列
```

**痛点**：
1. `asyncio.run` 每工具一次：开销 + 若宿主已在 async 上下文会抛 `RuntimeError`
2. `httpx.post` 同步：无法做流式输出
3. 工具串行（本链不改，B-2 解决）

---

## 三、设计方案

### 设计原则

- **渐进式**：保留旧同步方法（`run` / `chat`）作 feature flag 兜底，新增异步方法（`run_async` / `chat_stream`），逐端点切换
- **向后兼容**：`agent/cli.py`（POC）可继续用同步路径；工作台 router 切异步
- **接口先行**：`chat_stream` 的事件协议在本链冻结（供 B-3 前端并行开发）

### 统一流式事件协议（接口契约，冻结）

```python
# agent/events.py 或 agent/types.py

from dataclasses import dataclass
from enum import Enum


class EventType(str, Enum):
    TEXT_DELTA = "text_delta"
    REASONING_DELTA = "reasoning_delta"
    TOOL_CALL_START = "tool_call_start"
    TOOL_CALL_DELTA = "tool_call_delta"
    DONE = "done"
    ERROR = "error"


@dataclass
class StreamEvent:
    """统一流式事件（所有 Provider/LLMClient 的 stream() 都产出此类型）。

    【接口契约】B-1 冻结此协议，B-3（前端）按此开发，C（Provider）按此实现。
    """
    type: EventType
    content: str = ""                          # TEXT_DELTA / REASONING_DELTA
    tool_call: dict | None = None              # TOOL_CALL_START
    index: int = 0                             # TOOL_CALL_*（多工具时按 index 区分）
    delta: str = ""                            # TOOL_CALL_DELTA（参数增量）
    message: dict | None = None                # DONE（完整 message）
    usage: dict = None                         # DONE
    error: str = ""                            # ERROR
```

### 改动清单

#### 1. `agent/llm_client.py`：引入 AsyncClient + 流式

```python
import httpx
from agent.types import StreamEvent, EventType  # 统一事件协议


class LLMClient:
    def __init__(self, ...):
        # 同步客户端（保留，CLI/兼容用）
        self._client: httpx.Client | None = ...
        # 异步客户端（新增，流式用）
        self._aclient: httpx.AsyncClient | None = (
            httpx.AsyncClient(timeout=self.timeout) if self.base_url else None
        )
        # 流式累积器
        self._acc_content = ""
        self._tc_accum: dict[int, dict] = {}

    async def chat_stream(self, messages: list[dict], tools: list[dict] = None
                          ) -> typing.AsyncIterator[StreamEvent]:
        """异步流式调用，yield StreamEvent。

        【接口契约】B-1 冻结此方法签名，B-3/C 按此开发。
        """
        if self.is_mock:
            async for evt in self._mock_chat_stream(messages, tools):
                yield evt
            return

        clean_messages = self._clean_messages(messages)
        body = self._build_body(clean_messages, tools, stream=True)
        headers = self._build_headers()

        url = f"{self.base_url.rstrip('/')}/v1/chat/completions"
        async with self._aclient.stream("POST", url, json=body, headers=headers) as resp:
            if resp.status_code != 200:
                err = await resp.aread()
                yield StreamEvent(type=EventType.ERROR,
                                  error=f"HTTP {resp.status_code}: {err.decode()[:500]}")
                return

            async for line in resp.aiter_lines():
                if not line or not line.startswith("data: "):
                    continue
                payload = line[6:].strip()
                if payload == "[DONE]":
                    break
                try:
                    chunk = json.loads(payload)
                except json.JSONDecodeError:
                    continue
                for evt in self._parse_chunk(chunk):
                    yield evt

    def _parse_chunk(self, chunk: dict) -> list[StreamEvent]:
        """解析 OpenAI SSE chunk 为 StreamEvent（处理 delta + tool_calls 增量）。"""
        events = []
        choice = chunk.get("choices", [{}])[0]
        delta = choice.get("delta", {})
        if delta.get("content"):
            self._acc_content += delta["content"]
            events.append(StreamEvent(type=EventType.TEXT_DELTA, content=delta["content"]))
        for tc_delta in delta.get("tool_calls", []) or []:
            idx = tc_delta.get("index", 0)
            if idx not in self._tc_accum:
                self._tc_accum[idx] = {"id": "", "type": "function", "function": {"name": "", "arguments": ""}}
                events.append(StreamEvent(type=EventType.TOOL_CALL_START,
                                          tool_call=self._tc_accum[idx], index=idx))
            acc = self._tc_accum[idx]
            if tc_delta.get("id"):
                acc["id"] = tc_delta["id"]
            fn = tc_delta.get("function", {})
            if fn.get("name"):
                acc["function"]["name"] += fn["name"]
            if fn.get("arguments"):
                acc["function"]["arguments"] += fn["arguments"]
                events.append(StreamEvent(type=EventType.TOOL_CALL_DELTA,
                                          index=idx, delta=fn["arguments"]))
        if choice.get("finish_reason"):
            message = {
                "role": "assistant",
                "content": self._acc_content or None,
                "tool_calls": list(self._tc_accum.values()) or None,
            }
            events.append(StreamEvent(type=EventType.DONE,
                                      message=message, usage=chunk.get("usage", {})))
            self._acc_content = ""
            self._tc_accum = {}
        return events
```

**注意**：流式 tool_call 的参数是分片到达的（OpenAI 协议），必须按 `index` 累积——这是流式比非流式复杂的关键点。

#### 2. `agent/runtime.py`：新增 `run_async`

```python
class AgentRuntime:
    async def run_async(self, system_prompt: str, user_message: str,
                        session: SessionManager | None = None,
                        session_id: str | None = None) -> list[dict]:
        """异步核心循环（原生 async，工具仍串行——B-2 再做并行）。"""
        messages = [
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_message},
        ]
        if session and session_id:
            history = session.load(session_id)
            if history:
                messages = history
                self.events.emit("state", resumed=True, session_id=session_id)

        openai_tools = self._to_openai_tools()

        for turn in range(self.max_turns):
            if should_compact(messages, self.llm.max_context_tokens):
                messages = compact(messages, self.llm)
                self.events.emit("compaction", message_count=len(messages))
            self.events.emit("state", turn=turn, max_turns=self.max_turns)

            # 流式收集 message（同时 emit 增量事件）
            message, usage = await self._chat_and_emit(openai_tools)
            clean_message = self._clean_message(message)
            messages.append(clean_message)

            tool_calls = clean_message.get("tool_calls")
            if not tool_calls:
                break

            # B-1 阶段仍串行执行（B-2 再做并行）
            for tc in tool_calls:
                result = await self._execute_tool_async(tc)
                messages.append({
                    "role": "tool",
                    "tool_call_id": tc.get("id", ""),
                    "content": result,
                })
                self.events.emit("tool_call", tool_call=tc, result=result, turn=turn)

            if session and session_id:
                session.save(session_id, messages)
        else:
            if should_compact(messages, self.llm.max_context_tokens):
                messages = compact(messages, self.llm)
            messages.append({"role": "system", "content": f"[FUSE] 已达 max_turns={self.max_turns}"})
            self.events.emit("state", fused=True, max_turns=self.max_turns)

        if session and session_id:
            session.save(session_id, messages, metrics=self.llm.get_stats())
        return messages

    async def _chat_and_emit(self, openai_tools: list[dict]) -> tuple[dict, dict]:
        """流式调用 LLM，emit 增量事件，返回完整 message + usage。"""
        final_message = None
        final_usage = {}
        async for event in self.llm.chat_stream(self._current_messages, openai_tools):
            etype = event.type
            if etype == EventType.TEXT_DELTA:
                self.events.emit("assistant_delta", delta=event.content)
            elif etype == EventType.TOOL_CALL_START:
                self.events.emit("tool_call_start", tool_call=event.tool_call)
            elif etype == EventType.DONE:
                final_message = event.message
                final_usage = event.usage
                self.events.emit("assistant", message=final_message, usage=final_usage)
            elif etype == EventType.ERROR:
                self.events.emit("error", message=event.error)
                final_message = {"role": "assistant", "content": f"[错误] {event.error}"}
                final_usage = {}
        return final_message, final_usage

    async def _execute_tool_async(self, tool_call: dict) -> str:
        """异步执行单个工具（直接 await，无需 asyncio.run）。"""
        name = tool_call.get("function", {}).get("name", "")
        raw_args = tool_call.get("function", {}).get("arguments", "{}")
        try:
            arguments = json.loads(raw_args) if isinstance(raw_args, str) else raw_args
        except json.JSONDecodeError:
            return f"错误：参数 JSON 解析失败: {raw_args}"

        mod = self._tool_map.get(name)
        if not mod:
            return f"未知工具: {name}"

        try:
            result = await mod.handle(name, arguments)  # 直接 await，B-1 异步化的红利
            return result[0].text if result else "（无输出）"
        except Exception as e:
            return f"工具执行异常: {e}"

    # 保留旧同步入口（向后兼容，CLI 用）
    def run(self, system_prompt, user_message, session=None, session_id=None) -> list[dict]:
        """同步入口（向后兼容，内部委托 run_async）。"""
        return asyncio.run(self.run_async(system_prompt, user_message, session, session_id))
```

#### 3. `workbench/backend/routers/agent.py`：WS 端点切异步

```python
async def agent_ws(websocket, ...):
    ...
    runtime = AgentRuntime(llm, max_turns=max_turns, mode_name=mode_name)
    queue: asyncio.Queue = asyncio.Queue()
    runtime.events.subscribe(lambda e: queue.put_nowait(e))  # 不再 call_soon_threadsafe

    run_task = asyncio.create_task(
        runtime.run_async(system_prompt, message, sm, sid)
    )
    while True:
        if run_task.done() and queue.empty():
            break
        try:
            event = await asyncio.wait_for(queue.get(), timeout=0.1)
            await websocket.send_json(event)
        except asyncio.TimeoutError:
            continue
    messages = await run_task
```

HTTP 端点（`/api/agent/chat`）同理切 `await runtime.run_async(...)`，移除 `asyncio.to_thread`。
