# 任务链 J：通知配置（钉钉/飞书群聊）

> 优先级：**P0**（业务闭环的反馈出口，审计漏洞和运行失败都依赖它）
> 并行性：✅ 独立，可与任务链 H/I 并行（H/I 调 notify 接口，J 实现 webhook）
> 预计工期：3-4 天
> 文档依赖：[总览](./00-总览与任务链编排.md)、[任务链 H](./08-任务链H-闭环编排与模式自动路由.md)（漏洞通知）、[任务链 I](./09-任务链I-定时任务调度.md)（失败通知）

---

## 一、目标

实现「群聊通知出口」，让两类事件触达研发/测试人员的钉钉或飞书群：

1. **审计漏洞**（任务链 H 的 `report_vulnerability` 触发）→ 通知研发修正
2. **定时运行失败**（任务链 I 的 `execute_plan` 触发）→ 通知测试人员排查

**用户决策**：钉钉/飞书群聊（自定义机器人 webhook）。

---

## 二、现状

`feedback/notify.py` 存在但只留了通知出口的架子，未实现群聊 webhook。

## 三、设计方案

### DB 表：通知配置

```sql
CREATE TABLE IF NOT EXISTS notify_configs (
    id TEXT PRIMARY KEY,              -- notify-{uuid8}
    name TEXT NOT NULL,               -- 配置名（如 "TDM 研发群"）
    channel TEXT NOT NULL,            -- dingtalk / feishu
    webhook_url TEXT NOT NULL,        -- 机器人 webhook（加密存储，复用链 A-3 crypto）
    secret TEXT DEFAULT '',           -- 钉钉加签密钥（可选，加密存储）
    mention_mobiles TEXT DEFAULT '',  -- @ 手机号列表（逗号分隔，可选）
    events TEXT NOT NULL DEFAULT '["plan_failure","vulnerability"]',  -- 订阅事件
    enabled INTEGER NOT NULL DEFAULT 1,
    created_by TEXT NOT NULL,
    created_at TEXT NOT NULL
);
```

### `feedback/notify.py` 扩展

```python
"""通知出口：钉钉/飞书群聊 webhook。"""

import hashlib, hmac, base64, time, urllib.parse
import httpx


async def send_notification(config: dict, event: str, payload: dict) -> bool:
    """按配置发送通知。失败静默记录，不抛异常（通知不能阻塞主流程）。"""
    if not config.get("enabled"):
        return False
    try:
        if config["channel"] == "dingtalk":
            return await _send_dingtalk(config, event, payload)
        elif config["channel"] == "feishu":
            return await _send_feishu(config, event, payload)
    except Exception as e:
        _log_notify_failure(config["id"], event, str(e))
        return False


async def _send_dingtalk(config: dict, event: str, payload: dict) -> bool:
    """钉钉自定义机器人（markdown 消息 + 可选加签）。"""
    url = config["webhook_url"]
    # 加签（如果配置了 secret）
    if config.get("secret"):
        ts = str(round(time.time() * 1000))
        sign_str = f"{ts}\n{config['secret']}"
        sign = urllib.parse.quote_plus(base64.b64encode(
            hmac.new(config["secret"].encode(), sign_str.encode(),
                     hashlib.sha256).digest()))
        url = f"{url}&timestamp={ts}&sign={sign}"

    md_title, md_text = _render_markdown(event, payload)
    body = {
        "msgtype": "markdown",
        "markdown": {"title": md_title, "text": md_text},
    }
    # @ 人
    if config.get("mention_mobiles"):
        body["at"] = {"atMobiles": config["mention_mobiles"].split(","),
                      "isAtAll": False}

    async with httpx.AsyncClient(timeout=10) as client:
        resp = await client.post(url, json=body)
        return resp.status_code == 200 and resp.json().get("errcode") == 0


async def _send_feishu(config: dict, event: str, payload: dict) -> bool:
    """飞书自定义机器人（interactive 卡片）。"""
    card = _render_feishu_card(event, payload)
    async with httpx.AsyncClient(timeout=10) as client:
        resp = await client.post(config["webhook_url"],
                                 json={"msg_type": "interactive", "card": card})
        return resp.status_code == 200 and resp.json().get("code") == 0
```

### 消息渲染（两类事件）

```python
def _render_markdown(event: str, payload: dict) -> tuple[str, str]:
    """渲染钉钉 markdown。"""
    if event == "vulnerability":
        sev_icon = {"blocker": "🔴", "major": "🟠", "minor": "🟡"}[payload["severity"]]
        title = f"{sev_icon} Spec 漏洞：{payload['summary']}"
        text = (f"### {sev_icon} SpecGuard 发现 Spec 漏洞\n\n"
                f"- **类型**：{payload['vtype']}\n"
                f"- **严重度**：{payload['severity']}\n"
                f"- **位置**：{payload['location']}\n"
                f"- **证据**：{payload.get('evidence', '-')[:200]}\n"
                f"- **建议**：{payload.get('suggestion', '-')[:200]}\n\n"
                f"[查看详情]({payload.get('detail_url', '')})")
        return title, text

    if event == "plan_failure":
        title = f"❌ 定时任务失败：{payload['plan_name']}"
        text = (f"### ❌ SpecGuard 定时任务执行失败\n\n"
                f"- **计划**：{payload['plan_name']}\n"
                f"- **失败场景**：{payload['scenario_id']}\n"
                f"- **错误**：{payload.get('error', '-')[:300]}\n"
                f"- **时间**：{payload['run_at']}\n\n"
                f"[打开调试]({payload.get('debug_url', '')})")  # 链接带 context 触发 debug 路由（任务链 H）
        return title, text
```

**「打开调试」链接**：`{workbench_url}/agent?scenario={id}&run_failed=true` —— 前端带 context 打开 AgentChat，触发任务链 H 的模式路由（`last_run_failed=true` → 自动 debug），闭环衔接。

| 事件 | 触发位置 | 订阅方 |
|------|---------|--------|

## 四、风险与缓解

| 风险 | 缓解 |
|------|------|
| webhook URL 泄露 = 任何人可发群消息 | 加密存储（复用链 A-3）；前端只显示脱敏；文档提醒机器人设置关键词/加签 |
| 通知风暴（漏洞批量发现时刷屏） | `report_vulnerability` 批量合并：同一次 audit 的漏洞合并为一条摘要通知（>3 条时只发统计 + 详情链接） |
| 群机器人限流（钉钉 20 条/分钟） | 通知队列 + 简单限流（每分钟最多 10 条，超出合并） |
