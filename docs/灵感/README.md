# 灵感库索引

> 有价值但**暂不实施**的需求停车场。每个灵感独立一文件，沉淀「背景 → 需求本质 → 结论 → 设计要点 → 重启条件」，避免将来重启时重新讨论一遍。
>
> 与相邻目录的分工：`远期设计/` 是已立项排期的设计文档；`灵感/` 是想清楚了但未立项的想法；`经验包/` 是排障闭环沉淀。三者不混放。

## 登记协议

- **何时登记**：会话中出现有价值的需求构想、且已形成初步设计共识但决定暂缓时登记。纯随想、未讨论出形状的不入库。
- **文件命名**：`{日期}-{主题关键词}-{一句话定位}.md`
- **必备五段**：背景与触发场景 → 需求本质（一句话抽象）→ 结论（为何暂缓）→ 设计要点（重启时直接照此施工的颗粒度）→ **重启条件**（什么信号出现再捡起来）
- **纪律**：每条灵感必须有可判定的重启条件，不留「以后再说」式空话；重启条件命中时，升级为 `远期设计/` 正式设计文档并从本表标注迁移。
