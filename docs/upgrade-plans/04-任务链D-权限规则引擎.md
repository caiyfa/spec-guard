## 一、目标

把散落在各工具内部的安全逻辑抽象为集中式权限规则引擎，支持多用户场景的「危险操作二次确认」。

1. **D-1**：定义 `PermissionGuard` 集中式决策层
2. **D-2**：工具声明 `risk_level`，guard 按用户角色 + 操作类型决策
3. **D-3**：前端支持「危险操作确认」交互（**会话级记住 + admin 永久记住**）

## 二、设计方案（修正：记住机制分级）

### 「记住」机制分级（修正点）

| 选项 | 范围 | 权限 | 理由 |
|------|------|------|------|
| **本次会话内不再询问** | 当前 WS 会话（默认） | 所有用户 | 安全，换会话重新确认 |
| **永久不再询问** | 跨会话持久化 | **仅 admin** | 有安全风险（换人用同一账号），需 admin 确认 |

```python
# agent/permission.py 修正

class PermissionGuard:
    def __init__(self):
        self._session_allow: dict[str, set[str]] = {}  # session_id → tool_name 集合（会话级）
        self._always_allow: dict[str, set[str]] = {}    # emp_no → tool_name 集合（永久，仅 admin）

    def evaluate(self, request: PermissionRequest) -> PermissionResult:
        # 1. 会话级记住（当前会话内）
        if request.tool_name in self._session_allow.get(request.session_id, set()):
            return PermissionResult(decision=Decision.ALLOW, reason="本次会话内已允许", request=request)

        # 2. 永久记住（仅 admin 可设置）
        if request.tool_name in self._always_allow.get(request.emp_no, set()):
            return PermissionResult(decision=Decision.ALLOW, reason="用户已永久允许", request=request)

        # 3. 默认策略
        role_policy = DEFAULT_POLICY.get(request.role, DEFAULT_POLICY["tester"])
        decision = role_policy.get(request.risk_level, Decision.ASK)
        return PermissionResult(decision=decision, request=request)

    def grant_session(self, session_id: str, tool_name: str):
        """会话级记住（所有用户可用）。"""
        self._session_allow.setdefault(session_id, set()).add(tool_name)

    def grant_always(self, emp_no: str, tool_name: str, role: str):
        """永久记住（仅 admin 可设置）。"""
        if role != "admin":
            raise PermissionError("仅 admin 可设置永久允许")
        self._always_allow.setdefault(emp_no, set()).add(tool_name)
```

### 前端弹窗（修正：分级选项）

```tsx
function PermissionDialog({ request, userRole, onResolve }) {
  return (
    <Modal>
      <h3>确认执行：{request.tool_name}</h3>
      <p>风险等级：{riskLabels[request.risk_level]}</p>
      <pre>{JSON.stringify(request.arguments, null, 2)}</pre>
      <label>
        <input type="checkbox" name="session" /> 本次会话内不再询问（推荐）
      </label>
      {userRole === "admin" && (
        <label>
          <input type="checkbox" name="always" /> 永久不再询问（仅 admin）
        </label>
      )}
      <button onClick={() => onResolve({ granted: true, scope: ... })}>允许</button>
      <button onClick={() => onResolve({ granted: false })}>拒绝</button>
    </Modal>
  );
}
```

## 五、验收标准

| # | 验收项 | 验证方式 |
|---|--------|---------|
| 1 | tester 执行 db_evidence 时弹窗确认 | 用 tester 账号触发 |
| 2 | admin 执行 db_evidence 时直接通过（无弹窗） | 用 admin 账号触发 |
| 3 | 勾选「本次会话内不再询问」后，同会话内不再弹窗，新会话重新弹窗 | 重复触发 + 新建会话验证 |
| 4 | admin 勾选「永久不再询问」后，跨会话不弹窗 | 新建会话验证 |
| 5 | tester 勾选「永久不再询问」被拒绝（仅 admin 可设） | tester 账号验证 |
| 6 | 用户拒绝后，工具不执行，返回"用户取消" | 拒绝验证 |
