## 五、甜点 F-2-D：Hook 系统预留（暂不开发）

### 定位

为未来扩展预留，当前不实现。

### 预留设计（文档化，待需要时开发）

```python
# agent/hooks.py（未来新建）
from typing import Callable, Awaitable

HookPoint = str  # "before_tool" / "after_tool" / "before_llm" / "after_compact" ...

class HookRegistry:
    """Hook 注册表（参考 Pi 的 hook 全覆盖设计）。"""
    def __init__(self):
        self._hooks: dict[HookPoint, list[Callable]] = {}

    def on(self, point: HookPoint, callback: Callable):
        self._hooks.setdefault(point, []).append(callback)

    async def emit(self, point: HookPoint, *args, **kwargs):
        for cb in self._hooks.get(point, []):
            await cb(*args, **kwargs)
```

**Hook 点**（未来支持）：
- `before_tool(tool_name, args)` → 可拦截/改写
- `after_tool(tool_name, args, result)` → 可改写结果
- `before_llm(messages)` → 可改写消息
- `after_compact(messages)` → 可改写压缩结果

**触发开发的信号**：当出现「需要自定义校验规则」「需要拦截某些工具调用」等需求时启动。
