## 一、目标

单消息多 tool_call 并行执行：LLM 一次返回多个 tool_call（如同时 `read_spec` + `query_registry`）时并行执行，降低延迟。

**本链是 B-1 完成后的简单增强**——B-1 已完成异步化，B-2 只需把 `run_async` 内的 `for tc` 串行改成按 `parallel_safe` 分组的 `asyncio.gather` 并行。

---

## 二、设计方案

### 工具并行安全标记

参考 Pi 的 `executionMode`，给 MCP 工具加 `parallel_safe` 元数据：

**约定**（在 AGENTS.md 工具开发规范补充）：
- **只读工具**（read_* / query_* / list_* / validate）默认 `parallel_safe=True`
- **写工具**（write_draft / add_to_info_pack / undo_draft）`parallel_safe=False`
- **DB 工具**（db_evidence）`parallel_safe=False`（保守，避免连接竞争）

```python
# agent/runtime.py 新增

# 工具是否 parallel_safe 的判断（硬编码，与 mcp_server/tools 声明一致）
UNSAFE_TOOLS = {"write_draft", "add_to_info_pack", "undo_draft", "db_evidence"}

def _is_parallel_safe(tool_name: str) -> bool:
    return tool_name not in UNSAFE_TOOLS
```

### 并行执行逻辑

```python
async def _execute_tools_parallel(self, tool_calls: list[dict]) -> list[str]:
    """按 parallel_safe 分组：安全组并行，不安全组串行。

    策略：
    1. 把 tool_calls 分为 parallel_safe 与 sequential 两组
    2. parallel_safe 组用 asyncio.gather 并行
    3. sequential 组按原顺序串行
    4. 结果按原 tool_calls 顺序组装返回
    """
    results: dict[int, str] = {}
    safe_indices = [i for i, tc in enumerate(tool_calls)
                    if _is_parallel_safe(tc.get("function", {}).get("name", ""))]
    unsafe_indices = [i for i in range(len(tool_calls)) if i not in safe_indices]

    # 并行执行安全组
    if safe_indices:
        safe_tasks = [self._execute_tool_async(tool_calls[i]) for i in safe_indices]
        safe_results = await asyncio.gather(*safe_tasks)
        for i, r in zip(safe_indices, safe_results):
            results[i] = r

    # 串行执行不安全组
    for i in unsafe_indices:
        results[i] = await self._execute_tool_async(tool_calls[i])

    # 按原顺序返回
    return [results[i] for i in range(len(tool_calls))]
```

### runtime 集成

```python
# agent/runtime.py run_async 内（B-1 后的版本）

# 原（B-1 阶段，串行）：
# for tc in tool_calls:
#     result = await self._execute_tool_async(tc)
#     ...

# 新（B-2，并行）：
results = await self._execute_tools_parallel(tool_calls)
for tc, result in zip(tool_calls, results):
    messages.append({
        "role": "tool",
        "tool_call_id": tc.get("id", ""),
        "content": result,
    })
    self.events.emit("tool_call", tool_call=tc, result=result, turn=turn)
```
