## 贯穿全局的设计纪律（8 条铁律）

1. Agent 只建议，人拍板 2. 校验走确定性校验器 3. 每个产出必过闸
4. 链可跨界，资产不跨界 5. 被测系统经适配包解耦 6. 计划只能由 delta 导入生成
7. 诚实结果语义（绝不把环境问题报成 FAIL） 8. SpecGuard 不做编码智能体

## 关键跨模块数据流

```
材料包(M03) → 面试(M02) → 决策(M04) → 草案/冻结(M05) ─┬→ 禅道故事(M06)
                                                     └→ delta 导入 → 计划(M08) → 场景补齐(M07)
执行(M08) → 报告/归因(M09) → SPQ → ┬→ 禅道 BUG(M06)
                                   └→ 下轮面试信息包(M02/M03)  ⟳ 闭环
全部产物落笔即挂链 → 血缘链(M10) / 全景图谱(M11) ← 统一经 sf_external_refs(M06) 登记外部锚点
```
