## 根因

**代码按臆断契约消费 CLI 输出（`data.items` vs 实际 `data.messages` 等四处字段漂移），且拉取 0 条消息时仍无条件写文件并计成功——「诚实呈现」环节缺失**（实现层 + 测试层双缺口）。
