## 用途与用法

1. **全库定期扫描**（发版前/月度）：照「附：一键复扫」整段执行，逐条对照「通过标准」。
2. **评审新代码**：对照各条「问题形态」，命中即要求说明或修复。
3. 每条目结构 = **来源依据 → 问题形态 → 扫描命令 → 通过标准 → 实测基线**；所有命令均在**仓库根目录 Git Bash** 实跑验证过（2026-08-23），可直接复制执行。grep 零命中时退出码为 1，属正常。
4. 新命中先对照「通过标准」区分白名单/真问题；真问题修复后更新该条实测基线。
