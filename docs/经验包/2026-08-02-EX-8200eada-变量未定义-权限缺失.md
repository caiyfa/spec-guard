> 日期：2026-08-02 ｜ 任务号：EX-8200eada ｜ 环境：sit ｜ 工作区：tdm

## 现象

执行 `IS-PREP-002`（数据准备：创建活动→启动→创建会话→添加人员）失败：

```
E   Failed: [env_error] KeyError: "变量未定义: activity.json.data.id（可用键: ['env', 'activity_name', 'corp_code', 'corp_name', 'inv_date', 'activity']）"
```

表象：插值 `{{activity.json.data.id}}` 报变量未定义——第一反应容易怀疑场景写错或引擎插值链路。

## 证据链

1. `output.log`（`{workspace}/.specguard/reports/EX-8200eada/output.log`）：
   - 首个调用 `[SpecGuard] POST /api/system/activities → 200` **成功**（HTTP 层）
   - 第二个调用（PUT .../start）插值即炸
2. `cases/IS-PREP-002.json` 第一个 call 的 `body_excerpt`（**真相所在**）：
   ```json
   {"status": "500000", "message": "当前用户无平台权限，无法创建活动", "data": "当前用户无平台权限，无法创建活动"}
   ```
   —— HTTP 200 但**业务失败**（业务码 500000），`data` 是错误消息**字符串**而非对象 → `data.id` 不存在
3. `scenario_runner.py:311`：call 的 save 结构 = `{"status", "json", "headers"}`——`{{activity.json.data.id}}` 写法**正确**（poll docstring 同款）
4. 失败索引历史：`EX-22f2d142`（08-01）同因失败——非新问题
5. K-055 实测结论（08-01 已记录）：`resolve(TDM_INV_ACTIVITY, corp 1002) → SKIP「权限体系中找不到绑定资源码的账号」`

## 根因

**环节：环境（SIT 账号授权）**——`TDM_INV_ACTIVITY` 资源码在 SIT 权限体系**无绑定账号**；
default 账号（caiyunfei/90024166，配置注释声称 TDM_ADMIN）实际无活动创建权限。
场景/引擎/插值链路均无缺失；HTTP 200 掩盖业务失败是迷惑点。

## 修复

1. **场景侧（已实施，提交 2d969c4）**：T-305——IS-PREP-002/003、IS-RVT-001~003 五场景 flow 首步补
   `precheck_permission`（account default + resource_code TDM_INV_ACTIVITY + corp_code 1002），
   无权限时**首步诚实 SKIP**（K-055 R5 约定落地），不再运行期炸 FAIL。
   precheck 无 save → 契约指纹不变，release_check PASS。
2. **环境侧（待执行）**：SIT 为测试账号绑定写型资源码全集（TDM_INV_ACTIVITY /
   TDM_SNAPSHOT_ARCHIVE / TDM_GRID_RESULT / TDM_INV_OPERATION）——见《引擎升级建议-第二批》环境预置方案。
