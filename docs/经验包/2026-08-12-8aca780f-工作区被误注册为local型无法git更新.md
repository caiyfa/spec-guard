# 2026-08-12-sync失败-工作区被误注册为local型无法git更新

## 现象

会话 `20260812_144806_8aca780f`：`sync_workspace action=sync` 报「工作区 'tdm' 不是 git 型，不支持拉取」，工作区无法更新；用户反馈"之前是可以更新的"。

## 证据链

- `specstd/workspaces/registry.yaml`：tdm 的 `source.type: local`（path 指向 `_clones/tdm` 克隆目录）+ `active: ''`
- 但 `_clones/tdm` 是完整 git 克隆（`.git/config` 含 remote origin、FETCH_HEAD、refs/remotes/origin/master 均存在）
- 审计库 `audit_log`（workbench/backend/data/workbench.db）铁证：
  - id=21 `2026-07-27 16:04` `register_workspace tdm git`（正常 git 注册）
  - id=1180 `2026-08-11 17:11` `register_workspace tdm local`（**被 local 型重新注册覆盖**）
  - id=1181 同日 `grant_workspace tdm 90000001`
- 修复后 `pull('tdm')` 成功：`6aa29e650c05 → 84f011c3e970`，`changes/0817` 内容到位

## 根因

2026-08-11 17:11 通过 `POST /api/workspace/register-local` 把 tdm 工作区**以 local 型重新注册**（把 git 克隆目录 `_clones/tdm` 当本地文件夹路径注册），覆盖了 07-27 的 git 注册记录。`pull()/sync` 按 `source.type != "git"` 拒绝拉取 → 工作区失去更新能力。属**操作/配置层**问题（UI 或 API 误注册），非代码缺陷。

## 修复

- 手工修正 `specstd/workspaces/registry.yaml`：
  - `active: tdm`（恢复激活）
  - tdm 改回 git 型：`source: {type: git, url: http://gitlab.fehorizon.com/hr/TDM/ifelc-spec-tdm.git, branch: master, local_path: specstd/workspaces/_clones/tdm}`
  - `last_commit: 6aa29e650c05`（当前 HEAD）
- 关键坑：`local_path` 必须是**相对仓库根的完整路径** `specstd/workspaces/_clones/tdm`（`clone_path.relative_to(SG_ROOT)` 的产物），写成 `_clones/tdm` 会导致 `root` 解析到不存在的 `{SG_ROOT}/_clones/tdm`（少一层）

## 预防

- 可执行检查清单：
  1. 重新注册同名工作区前，先查 `audit_log` 确认既有注册类型（git 型被 local 覆盖 = 失去更新能力）
  2. 前端「注册本地工作区」时禁止选择 `specstd/workspaces/_clones/` 内部目录（git 克隆落点不应被注册为 local 源）
  3. 排查"工作区不能更新"先看 `registry.yaml` 的 `source.type` 与 `active` 是否与审计记录一致
  4. `registry.yaml` 修复时 `local_path` 用 `specstd/workspaces/_clones/{name}` 完整相对路径
