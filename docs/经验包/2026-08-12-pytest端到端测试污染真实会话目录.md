# 2026-08-12-pytest端到端测试污染真实会话目录

## 现象

工作台「会话列表」出现大量空会话（无任何消息内容，仅 meta 行），用户侧表现为"莫名其妙多出来很多空会话"。本次排查时 `agent/sessions/90024166/tdm/` 下共 258 个空会话，全部工号合计 373 个，其中今日 8 个（`20260812_111355_f503ccd8` 等）与 pytest 运行时间精确吻合（11:13:55 / 11:15:19）。

## 证据链

- 空会话文件内容仅一行 `{"_type": "session_meta", ..., "purpose": "test_workbench", "tool_whitelist": [], "archived": true}`，无任何 user/assistant/tool 消息行
- `test_specstd/test_purpose.py::TestPurposeEndpoints` 的 `client` fixture 仅做 `sys.path` 处理，**无 DB / sessions 目录隔离**；其 `test_create_session_with_purpose` / `test_patch_purpose_409` / `test_list_sessions_purpose_filter` 通过 `POST /api/agent/sessions` 以真实工号 90024166 创建会话，落盘真实 `agent/sessions/{emp}/{ws}/`（`routers/agent.py` 模块级 `SESSIONS_ROOT`）
- `test_specstd/test_multiuser.py` 的 `client` fixture 注释声称"隔离 sessions"，但未 monkeypatch `SESSIONS_ROOT`，其归档测试（`batch-archive`）产生大量 `archived: true` 空会话
- `test_create_session_viewer_denied` 隐式依赖真实 DB 中历史测试残留的 viewer 用户 90024170（隔离后首个用户 bootstrap 为 admin，测试失败）

## 根因

**测试基建缺失**：`TestClient` 端到端测试未隔离后端模块级存储路径（`user_store.DB_PATH` / `routers.agent.SESSIONS_ROOT`），每次跑测试都在真实仓库写入空会话；历史多轮测试累积 300+ 个。

## 修复

1. `test_purpose.py::TestPurposeEndpoints.client` fixture：monkeypatch `user_store.DB_PATH` → tmp_path、`routers.agent.SESSIONS_ROOT` → tmp_path（import 前先加 sys.path）
2. `test_multiuser.py::client` fixture：补 `SESSIONS_ROOT` → tmp_path 隔离
3. `test_create_session_viewer_denied`：显式 `upsert_user + set_roles(["viewer"])`，不再依赖隐式 DB 状态
4. 清理污染：删除全部 meta-only 空会话 373 个（含配套 _meta.json/_metrics.jsonl，脚本判定标准 = jsonl 仅一行 session_meta）；另删旧格式空会话 1 个
5. 修复后验证：test_purpose + test_multiuser 65 例全绿，跑测试前后 `agent/sessions` 文件数零变化

## 预防

- **TestClient 端到端测试三隔离是标配**：`user_store.DB_PATH`、`routers.agent.SESSIONS_ROOT`、`specstd.workspace.REGISTRY_PATH/CLONES_DIR`，缺一不可（对照 test_multiuser.py 完整 fixture）
- 新增后端 TestClient 测试前，先检查 client fixture 是否已隔离全部存储路径
- 跑完含 TestClient 的测试后查 `git status` / 会话目录文件数，确认零污染
