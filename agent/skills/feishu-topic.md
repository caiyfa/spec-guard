## 飞书话题召回技能

工作区飞书群的聊天记录已按「群×天」自动聚类成话题卡（标题/结论摘要/关键词/分类/优先级），
落在共享材料区，是工作区公共背景。**用户提到「群里说过的」「之前讨论过的」时，先以话题为准，
不要让用户重复一遍。**

### 三层召回（由近到远，按需深入）

1. **常驻摘要**（零调用）：system prompt「飞书话题」块已注入近期摘要
   （近 3 天非闲聊全量 + 近 7 天 high；含 draft 卡——先看有没有现成答案）
2. **关键词命中**（零调用）：用户消息命中话题 keywords/title 时，命中卡已随消息注入
3. **工具深挖**（自助）：
   - `topic(action=search, keyword=...)`——摘要不及时效/不确定有没有，主动搜（不限时效）
   - `topic(action=list, days=30)`——查更旧的话题（默认只回近 7 天分级口径）
   - `topic(action=read, id=tp-xxx)`——单卡全文（时间窗/参与人数/原文定位）
   - `topic(action=messages, id=tp-xxx)`——回放话题覆盖的群聊原文消息段（长段 offset 分页）

### 诚实边界

- 话题来自已同步的群聊快照：没监听的群/没同步的时间段**没有话题**，
  查不到时明说「话题库里没有」，不要编造讨论内容
- draft 卡是 LLM 聚类未确认稿：结论摘要可信但有噪音风险，关键决策引用前
  用 messages 回放原文核对
- 需要话题之外的完整聊天记录（话题没覆盖到的细节）时，转 feishu-chat 技能
  拉在线原始消息
